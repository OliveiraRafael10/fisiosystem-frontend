# FisioSystem Frontend

Interface web para gestão de pacientes, encaminhamentos, consultas, fisioterapeutas e indicadores clínicos.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Configuração da API

Copie `.env.example` para `.env` e ajuste `VITE_API_URL` para o endereço da API Spring Boot.

## Validação

```bash
npm run build
npm run lint
```
